# Carevia Hospital — Master Demo

Reusable white-label hospital website demo for client presentations.

## UX focus
- Doctor search
- Doctor profiles with speciality and OPD timings
- Department discovery
- Emergency visibility
- Appointment request flow
- Health-check packages
- Patient information and contact
- Mobile-first Book / Doctors / Emergency actions
- English, Hindi and Marathi switcher

## Visual direction
Premium hospital UI with a calm blue clinical palette, clean cards, strong emergency hierarchy, large mobile tap targets and short patient-friendly content.

## Demo note
All doctors, timings, services, emergency numbers, locations, insurance information and other details are placeholders and must be replaced before launch.
